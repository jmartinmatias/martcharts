Embed a chart

Each example below is the code under it, live: copy it into any page, with no build step.

Which bundle

  • martcharts-lite.iife.js : to show charts and dashboards. Most pages need only this one.
  • martcharts.iife.js : everything, the editor and composer too.
  • martcharts-reading.iife.js : add it after either one for chart explanations in French and German.

The spec inside the tag

Data, fields and the chart in one block of JSON.

A spec file

Any widget saved as JSON, from the editor or the catalog.

A CSV file

As exported from a spreadsheet: the first row names the fields.

Just a data file

No spec at all: the chart is picked from the data's shape.

From JavaScript

Set the spec from code; here the data is a function that runs in the page.

In an iframe, on any site

For sites that cannot load scripts: the frame sizes itself to the chart.
